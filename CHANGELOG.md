# Changelog

All notable changes to `deep-ui-qa` are documented here.

## [1.1.0] — 2026-11-24

- Run contracts: authorized origins, allowed/forbidden actions, mutation budget, data classification, evidence retention, time anchor and end state.
- Anomaly triage funnel; only a confirmed `Defect` becomes `Fail`.
- FEW HICCUPPS oracle completeness with multiple oracle families for high-impact outputs.
- Feature-complete configuration matrix; stacked, isolate and control fixture designs.
- Multi-cycle and stage-reconciliation lens.
- AI-assisted/generative UI lens and a WCAG 2.2 AA minimum manual pass.
- Untrusted-content boundary, authorized-origin navigation and evidence-privacy rules.
- Summary reconciliation, module traceability, anomaly-triage counts and stricter validation.
- Synthetic demo workspace and pre-generated workbook under `examples/`.

## [1.0.0] — 2026-11-04

Initial release.

- Nine-phase workflow: intake, recon, atlas, model, design, execute, second look, report, cleanup.
- Model-first black-box testing with perturbation experiments and cross-module relationship mapping.
- Layered test design catalog with per-control checklists and deep scenario lenses.
- Evidence discipline: oracle hierarchy, multi-surface verification, honest statuses, config ledger.
- Workspace initializer, validator and styled Excel report builder.
- Seven domain packs: SaaS, HR/payroll, finance, e-commerce, CRM, support, scheduling.
- Host compatibility guidance for Claude Code, OpenCode, Codex, Cursor, Windsurf, Gemini CLI and Copilot.
- Installers for bash and PowerShell, plus CI smoke tests.
